Website/Image Screenshot Service

—

Screenshot:

Enter a URL and click Generate or use quick size buttons

API Info:

Base URL: https://img.gitgpt.chat/

Parameters:

  • url - Website URL or image URL
  • w - Width in pixels (default: 1280)
  • h - Height in pixels (default: 720)
  • fit - Fit mode: cover, contain, fill (default: cover)
  • rc=1 or c=1 - Force refresh/clear cache

Example: https://img.gitgpt.chat/?url=github.com&w=512&h=512&fit=cover&rc=1
